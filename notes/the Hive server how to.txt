server updating:
 updating the server will not affect any of the docker container as they are isolated systems. 

 download updates: 
  run: sudo apt update

 install updates:
  run: sudo apt upgrade -y

 after updating, reboot the server.

rebooting the server:
 run: sudo reboot

docker containers on the server:

 show all running containers:
  run: docker ps

 show all containers running or not:
  run: docker ps -a 
 
 show container sizes
  run: docker ps -s

 show container specific details:
  run: docker container ls -a
 
show all containers in a nice format:
  run: docker ps -a --format "table {{.Names}}\t{{.Image}}\t{{.Status}}\t{{.Ports}}"

to start a docker container 
  run: docker start [container_name]

 how to connect to a container:
  connect to the docker with bash:
   docker exec -it <container_name_or_id> /bin/bash

  connect to the docker with sh:
   docker exec -it <container_name_or_id> /bin/sh

 how to run a single command in a container:
  docker exec <container_name> <command>
